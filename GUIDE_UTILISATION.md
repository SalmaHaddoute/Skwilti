# 📖 Guide d'Utilisation - Skwilti

## 🎯 Introduction

Bienvenue dans Skwilti, la plateforme pédagogique intelligente! Ce guide vous aidera à utiliser toutes les fonctionnalités de l'application selon votre rôle.

---

## 👨‍🏫 Guide Enseignant

### 1. Créer une Classe

**Étapes**:
1. Accédez au tableau de bord enseignant
2. Cliquez sur "Créer une classe"
3. Remplissez les informations:
   - Nom de la classe
   - Description
   - Catégorie (Mathématiques, Français, etc.)
   - Niveau (Primaire, Collège, Lycée)
4. Cliquez sur "Créer"
5. Partagez le code d'invitation avec les étudiants

### 2. Créer un QCM

**Étapes**:
1. Sélectionnez une classe
2. Cliquez sur "Créer un QCM"
3. Remplissez les informations:
   - Titre du QCM
   - Description
   - Matière
4. Ajoutez les questions:
   - Texte de la question
   - Options de réponse
   - Bonne réponse
   - Explication (optionnel)
5. Cliquez sur "Publier"

**Utiliser l'IA**:
- Cliquez sur "Générer avec IA"
- Entrez le sujet
- L'IA génère automatiquement les questions

### 3. Uploader un Cours

**Étapes**:
1. Sélectionnez une classe
2. Cliquez sur "Uploader un cours"
3. Remplissez les informations:
   - Titre du cours
   - Description
   - Matière
4. Sélectionnez le fichier (PDF, image, etc.)
5. Cliquez sur "Uploader"

### 4. Voir les Résultats des Étudiants

**Étapes**:
1. Accédez au tableau de bord
2. Sélectionnez une classe
3. Cliquez sur "Résultats"
4. Consultez:
   - Scores des étudiants
   - Progression
   - Statistiques

### 5. Gérer les Étudiants

**Ajouter un Étudiant**:
1. Sélectionnez une classe
2. Cliquez sur "Gérer les étudiants"
3. Cliquez sur "Ajouter"
4. Sélectionnez l'étudiant
5. Cliquez sur "Ajouter"

**Supprimer un Étudiant**:
1. Sélectionnez une classe
2. Cliquez sur "Gérer les étudiants"
3. Cliquez sur l'icône de suppression
4. Confirmez

### 6. Créer une Room (Salle Virtuelle)

**Étapes**:
1. Cliquez sur "Créer une room"
2. Remplissez les informations:
   - Nom de la room
   - Description
3. Cliquez sur "Créer"
4. Partagez le code avec les étudiants
5. Les étudiants rejoignent avec le code

## 👨‍🎓 Guide Étudiant

### 1. Rejoindre une Classe

**Étapes**:
1. Accédez au tableau de bord
2. Cliquez sur "Rejoindre une classe"
3. Entrez le code d'invitation
4. Cliquez sur "Rejoindre"
5. La classe apparaît dans votre liste

### 2. Répondre à un QCM

**Étapes**:
1. Sélectionnez une classe
2. Cliquez sur "QCM disponibles"
3. Sélectionnez un QCM
4. Lisez la question
5. Sélectionnez votre réponse
6. Cliquez sur "Suivant" ou "Terminer"
7. Consultez votre score

### 3. Consulter les Résultats

**Étapes**:
1. Accédez au tableau de bord
2. Cliquez sur "Mes résultats"
3. Consultez:
   - Scores récents
   - Progression
   - Statistiques

### 4. Voir la Progression

**Étapes**:
1. Accédez au tableau de bord
2. Cliquez sur "Ma progression"
3. Consultez:
   - Graphique de performance
   - Scores par matière
   - Tendances

### 5. Rejoindre une Room

**Étapes**:
1. Cliquez sur "Rejoindre une room"
2. Entrez le code de la room
3. Cliquez sur "Rejoindre"
4. Participez en temps réel

### 6. Consulter les Cours

**Étapes**:
1. Sélectionnez une classe
2. Cliquez sur "Cours"
3. Sélectionnez un cours
4. Consultez le contenu
5. Téléchargez si nécessaire

## 💳 Gestion des Abonnements

### Types d'Abonnements

**Freemium** (Gratuit)
- 1 QCM par jour
- Accès limité aux fonctionnalités
- Pas de support prioritaire

**Basic**
- 5 QCM par jour
- Accès à la plupart des fonctionnalités
- Support par email

**Premium**
- QCM illimités
- Accès complet à toutes les fonctionnalités
- Support prioritaire
- Génération IA avancée

### Changer d'Abonnement

**Étapes**:
1. Accédez au profil
2. Cliquez sur "Abonnement"
3. Sélectionnez le nouveau plan
4. Cliquez sur "Mettre à jour"
5. Complétez le paiement
